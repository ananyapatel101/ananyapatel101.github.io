2. SAP S/4HANA FICO End-to-End Implementation: XYZ Pvt Ltd

One fictional company code (IN10) set up and run end to end, in five parts that follow the order of the work. Every part posts into the same set of books, so the supplier, customer and asset balances all tie to the 30 September Balance Sheet and P&L in Part 5.

Part 1 of 5 · SAP FI · Enterprise structure & global settings

End-to-End Financial Accounting Setup

Configured company code IN10 from a blank client to its first valid posting: company, ledger 0L, fiscal year variant V3, posting periods with a restricted audit period, field status, document types, number ranges and tolerance groups. Twelve unit tests prove each control, and a posting simulator runs them.

Part 2 of 5 · SAP MM–FI integration · Accounts Payable

Procure-to-Pay (P2P)

Ran a purchase end to end in IN10: requisition, PO, two goods receipts, a three-way-matched MIRO invoice with GST input credit, then an F110 payment. Configured OBYC account determination, OMR6 tolerances and the payment program. Twelve unit tests cover blocks, duplicates and due dates, and the GR/IR balance ties to Part 5's trial balance.

Order-to-Cash (O2C)
